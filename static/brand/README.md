# Chess Lab

Monochrome Wort-Bild-Marke, 27.09.2026. Das eigene SVG-Signet verbindet einen Bauern mit einem Laborkolben. Die Wortmarke kombiniert eine Serifenschrift für „Chess“ mit einem kleineren, gesperrten „LAB“ in serifenloser Schrift.

- `chess-lab-mark.svg`: transparentes, skalierbares Signet; Farbe über currentColor.
- `chess-lab-logo.svg`: schwarze Wort-Bild-Marke auf transparentem Hintergrund, Text bleibt editierbar.
- `favicon.svg`: Browser-Icon mit heller/dunkler Darstellung.

Die App nutzt das Signet direkt als SVG und lokale Systemschriften. Keine zusätzlichen Schrift- oder Bilddownloads nötig.
